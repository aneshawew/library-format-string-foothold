Files derived from the handout and the lab's own provided source
------------------------------------------------------------------
- provisioning/roles/victim/templates/format.c.j2
    Identical to the format.c you provided, except the `secret` string
    is templated to this sandbox's APG flag_task4 value. Every other
    line (BUF_SIZE handling, myprintf(), main(), dummy_function()) is
    unchanged.

- provisioning/roles/victim/templates/server.c.j2
    Identical to the server.c you provided, except the PROGRAM and PORT
    #defines are wrapped in #ifndef guards with the same default values,
    so one source file can be compiled twice (server32 / server64) with
    different -D overrides. No behavior changed; nothing else edited.

- provisioning/roles/victim/templates/Makefile.j2
    Your Makefile, with L templated to this sandbox's APG buf_size value,
    TARGET extended to server32/server64, two new build rules for them,
    and the Docker-specific `install` rule removed (no container build
    context exists in this topology).

- provisioning/roles/attacker/files/attack-code/build_string.py
  provisioning/roles/attacker/files/attack-code/exploit.py
    Reproduced unmodified from the handout's own attack-code/ scaffolding.
